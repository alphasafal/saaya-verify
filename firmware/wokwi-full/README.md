# SAAYA Node: full hardware simulation in Wokwi

This folder is the complete SAAYA Node in [Wokwi](https://wokwi.com). It runs the **real firmware** (`firmware/src/main.cpp`, field build) on an emulated ESP32-DevKitC V4. Every part is wired to the same pins as the hardware:

| Part | Wokwi part | ESP32 pins |
|---|---|---|
| SSD1306 OLED | `board-ssd1306` (0x3C) | IO21 SDA, IO22 SCL |
| SHT30 seat sensor | custom chip `sht30`, address 0x44 (ADDR → GND) | IO21, IO22 |
| SHT30 reference sensor | custom chip `sht30`, address 0x45 (ADDR → 3V3) | IO21, IO22 |
| Fan branch: 2N3904 + Arctic P12 Pro + INA219 | custom chip `saaya-fan` (INA219 at 0x40) | IO25 PWM, IO34 tach (10 kΩ pull-up) |
| DS18B20 roof probe | `wokwi-ds18b20` + 4.7 kΩ | IO4 |
| MODE / HELP / ACK buttons | `wokwi-pushbutton` to GND | IO32 / IO33 / IO27 |
| Help/fault LED | `wokwi-led` + 330 Ω | IO26 |
| Buzzer | `wokwi-buzzer` | IO14 |
| Float switch | `wokwi-slide-switch` + 10 kΩ pull-up | IO35 |

Wokwi has no SHT3x, INA219 or 4-wire fan part, so two **custom chips** written in C (`*.chip.c`) provide them. They speak the real protocols: the SHT30 returns datasheet CRC-8-checked words, and the fan chip inverts the PWM like the 2N3904, outputs 2 tach pulses per revolution and exposes INA219 registers (current = shunt × CAL / 4096, power = current × bus / 5000). Both chips were compiled with Wokwi's compiler flags and tested against the same I²C transactions the Adafruit libraries make (`tests/wokwi-chips.test.mjs`).

## Run it on wokwi.com (free, in the browser)

1. Open **https://wokwi.com/projects/new/esp32** and sign in (needed to save and to use custom chips).
2. Open `sketch.ino` in this folder, copy all of it, and paste it over the editor’s `sketch.ino`.
3. Do the same for `diagram.json` (the tab next to `sketch.ino`).
4. Add the remaining files with the small ▾ arrow beside the file tabs → **Upload file(s)…** (or **New file…** and paste): `controller.h`, `libraries.txt`, `sht30.chip.json`, `sht30.chip.c`, `saaya-fan.chip.json`, `saaya-fan.chip.c`. File names must be exactly these. Do not upload `vendor/`: Wokwi supplies its own `wokwi-api.h`.
5. Press the green **Play** button. The first build takes about a minute while Wokwi compiles the libraries and the chips.
6. Save the project (Ctrl/Cmd + S) so you can open it again without repeating steps 2–4.

The website also has the same files as one zip: `downloads/saaya-node-wokwi.zip`.

## Demo script (3 minutes)

- **Serial monitor:** one JSON record per second, the same format the real node sends.
- **Automatic fan:** click the `seat` SHT30 chip and move *Temperature* to 33 °C. Within a second the fan starts at 50 % (OLED: `Fan 50% … RPM`). The *Chips Console* shows the fan chip’s rpm and current.
- **39 °C cut-off:** move the seat temperature to 40 °C. Automatic fan stops and the OLED shows `HOT: FAN MAY ADD HEAT`. Press **MODE**: manual 70 % still works.
- **Fan fault:** click the `fan` chip and set *Fan blocked* to 1. After 3 s the OLED shows `FAN FEEDBACK FAULT` and the LED lights.
- **Help latch:** press **HELP**: LED, buzzer and OLED latch. Restart the simulation (stop and play): the latch is restored from flash. Press **ACK** to clear it.
- **Sensor fault:** set *Connected* to 0 on the `reference` chip: `SENSOR FAULT`, automatic fan inhibited, values sent as `null`.
- **Water:** slide the float switch to the right: `WATER LOW / CHECK`.

## Run it locally (VS Code or wokwi-cli)

```sh
pio run -d firmware -e esp32dev_field   # firmware
make -C firmware/wokwi-full             # custom chips -> dist/*.chip.wasm (needs clang + wasi-libc)
```

Then open `firmware/wokwi-full` with the Wokwi VS Code extension (`wokwi.toml` points to both).

## Files

`sketch.ino`, `controller.h`, `diagram.json` and `libraries.txt` are generated by `python scripts/build_wokwi_full.py` from the firmware sources, so they stay in step with the hardware build. The custom chips are hand-written: `sht30.chip.*` and `saaya-fan.chip.*`.

Note: the fan’s speed and current are a model (0 rpm below 5 % input, about 3,000 rpm at 100 %, 12 V × (0.03 + 0.30 × (rpm/3000)²) A), not a measurement.
