# Present SAAYA VERIFY

## A two-minute demonstration

1. Open the public demo. Rotate the shelter, switch to front/top views, toggle **Explode**, and select the dry enclosure or fan mount. Explain that the printable meshes are fabrication candidates; electronic components are placement envelopes pending fit checks.
2. Open **IoT architecture and local working flow**. Follow paired environmental sensors → ESP32 → fan/display → USB bridge → local API/database → evidence. Manual controls and the assistance latch are local. Pages hosts the demonstrator, not the API.
3. Choose **Normal operation** and **Seated air speed**, start and complete the replay. Identify the **SIMULATED** label before discussing any number. Export the JSON to inspect the same samples used for the conclusion.
4. Reset, choose **Fan failure**, repeat the air-speed comparison, and show the withheld conclusion. Try **Unavailable power** to show that missing power is unavailable rather than zero. The reference-mismatch scenario demonstrates why matched observations matter.
5. Show research access/limitations, cost allowances and the drawbacks. Describe the proposed contribution as a repairable shelter experiment with auditable comparison records. Worldwide novelty and thermal effectiveness are not established.

## What has actually been built

The public application, local telemetry/experiment API, deterministic evaluator, optional read-only model adapter, ESP32 firmware source, parametric CAD and release workflow are software artifacts. The verification record states which builds/tests have run. There is no assembled physical prototype or measured cooling dataset in this release.

## Workshop handoff

Use `engineering.md` for the pin map, driver, power boundary and assembly order. Measure the purchased board/display/fan before fabrication; select compatible substituted parts and update configuration records. Print a fit coupon and verify clearances, fasteners, service access and cable routing before a complete set. Use `physical-protocol.md` for unoccupied paired tests with independent instruments. Do not interpret a miniature result as full-size performance.

Procurement, fabrication, electrical inspection, physical fault injection, calibration and thermal trials remain required. The separately budgeted full-size concept needs a structural/installation design and actual local quotes before construction.
